# Netflix Analytics Dashboard

## Réalisé par:
Hiba Kourda & Farah Gritli

## Description
Ce projet consiste à analyser le catalogue Netflix à travers un dashboard interactif développé avec Streamlit et Plotly.

## Objectifs
- Étudier les films et séries
- Analyser les genres
- Visualiser les pays producteurs
- Étudier les ratings
